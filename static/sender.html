Quick help

Dashboard

Start or stop the stream here. A small live input preview, input peak, source status and computer resources remain visible in the sidebar. The preview refreshes at up to 5 fps while this page is visible; it is not a latency measurement or an extra viewer connection. Disable Live input preview in Setup to pause thumbnails without restarting the stream. Viewer diagnostics show the latest client report; Connections shows each viewer separately.

Signal and stream alerts

The source name and Signal present are green; with No signal or Stopped, the source and status are red. The orange message in the Stream bar identifies missing input, source/server errors, encoder budget overruns and new video/audio drops. Encoding alerts trigger when P95 exceeds the frame budget or at least 5% of the recent samples exceed it. Drop alerts compare consecutive reports, so old losses do not remain an active warning.

Encoding time and frame budget

The encoding time is the 95th percentile of the latest 100 encoded frames: approximately 95% took this long or less. It measures encoding work, not viewer latency. At 50 fps, the frame budget is 20 ms; at 25 fps, it is 40 ms.

Green: no measured frames exceeded the budget. Amber: some frames exceeded it. Red: the 95th-percentile time exceeds the budget, indicating limited encoding headroom. Check frame rate and picture stability as well; an isolated spike does not prove visible stuttering. A dash means no measurements are available yet. Hover over the timing value for the average and sample count.

Distribution

Go / Pion handles WebRTC connections and sends the encoded stream to each viewer. Each video format is encoded once and shared. Network traffic increases with viewer count. AV1 and H.264 share the Opus audio stream.

Automatic process supervision

The standard FastVideo launcher monitors its server and gateway processes and restarts them if they exit unexpectedly. This is automatic, with no dashboard setting. It does not guarantee an uninterrupted picture or restart a stalled source. Source recoveries are counted separately.

Setup and viewer links

Select an NDI or OMT source and adjust AV1 / H.264 bitrate and quality in Setup. Applying encoder settings reconnects the pipeline and viewers. SDI2OMT stays external; select its OMT output as a normal source. Viewer links contains the public and local playback links.

Latency

WebRTC RTT is the network round-trip time. Buffer and decode times describe browser processing. Timestamp latency starts at the FastVideo input; estimated clock correction and upstream source delays can differ from a photo comparison of the original and received picture.
