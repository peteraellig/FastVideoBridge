FastVideo Bridge - Build from source (Windows x64)

Prerequisites: Python 3.12 x64, Go 1.26 or newer on PATH.
Run these commands in PowerShell from the repository root:

  py -3.12 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r documents\requirements.lock.txt
  Copy-Item fastvideo.settings.example.json fastvideo.settings.json
  Push-Location gateway
  go build -mod=vendor -trimpath -o fastvideo-gateway.exe .
  Pop-Location
  .\Start-Bridge.bat

Stop with Stop-Bridge.bat. Local UI: http://127.0.0.1:18879/sender
Do not overwrite an existing personal fastvideo.settings.json.
Go's vendored dependencies include a local GoSRT patch: do not regenerate
or remove gateway/vendor without preserving it (see gateway/SRT-VENDOR-PATCH.md).
The OMT DLLs and their license are included under vendor/omt.
For NDI install NDI Tools separately; for SDI install Blackmagic Desktop Video.

Optional Windows installer:
Install Inno Setup 7 (or pass -CompilerPath to the build script).
Download Python 3.12.10 Windows embeddable package (64-bit) from python.org:
https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip
Save it as installer/tools/python-3.12.10-embed-amd64.zip.
After building the gateway and creating the settings file above, run:

  .\installer\Build-BridgeInstaller.ps1 -Lean -PythonExe "$PWD\.venv\Scripts\python.exe"

The installer build includes its required payload/installation verifier.
This verifier installs into a temporary folder and starts that temporary copy.
The application test suites and gateway load generator are not included.

Export contents:
- Application sources, UI assets, build instructions and dependency licenses.
- OMT runtime libraries (required native dependencies, not generated app output).
- No original Git history, personal settings, work data, logs or test suites.
- The prebuilt installer is in dist locally and published as a GitHub Release asset.
- installer/tools downloads are intentionally excluded from Git.
- documents/ contains only requirements.txt and requirements.lock.txt.

This export has not been compiled or runtime-tested on the export machine.
