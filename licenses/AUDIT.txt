Remaining provenance gaps / limits
---------------------------------
- pyav-ffmpeg's original 8.1.1-2 binary release asset was unavailable through
  the GitHub releases API at audit time. The tagged recipe and its pinned
  source archives remain available and have been preserved.
- Its Windows build script copies libgcc_s_seh-1.dll, libstdc++-6.dll,
  libwinpthread-1.dll, libiconv-2.dll and zlib1.dll from the compiler's bin
  directory without recording exact MSYS2 package revisions in that recipe.
  The wheel records the repaired DLLs, but not all source-package revisions.
- Identified upstream versions: GCC strings identify 15.2.0; libiconv identifies
  1.19; zlibVersion() returns 1.3.2. Those upstream source releases are included.
  Exact MSYS2 revisions, patches and original build options have not been
  established, so these upstream releases are NOT asserted to constitute
  verified complete corresponding source for every copied runtime DLL.
- winpthreads' upstream COPYING is from the official mingw-w64 repository:
  https://raw.githubusercontent.com/mingw-w64/mingw-w64/master/mingw-w64-libraries/winpthreads/COPYING
  Its specific binary's source revision remains unconfirmed.
- No commercial redistribution exception for x264/x265 was obtained or assumed.
- No binary rebuild, installer execution, hardware test or patent assessment
  was performed. This is a source/license provenance audit, not a blanket
  compliance certification. Complete binary provenance remains an open item.

Source package interpretation
-----------------------------
The source bundle preserves original archives and patches, not a claim that
all binaries can already be reproduced bit-for-bit. Use the upstream recipe
and its platform/toolchain instructions. Preserve the recorded hashes when
reconstructing a build. Original upstream test/build files inside dependency
archives are retained because they are part of the upstream source packages.
The application snapshot is exported from the repository commit recorded in
APPLICATION-SOURCE-COMMIT.txt in the source bundle.
